# Control-Capex 📊

Sistema para el control y seguimiento de gastos de capital (CAPEX).

## 📝 Descripción
Este proyecto permite gestionar inversiones, activos fijos y presupuestos de capital.

## 🚀 Funcionalidades planeadas
- Registro de activos
- Seguimiento de presupuestos
- Reportes de inversión
- Dashboard interactivo
